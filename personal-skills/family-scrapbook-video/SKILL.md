# 家庭手账记录片

这是用户确认过的个人视频风格。以真实家庭素材为主，用手账设计组织内容。默认竖屏 9:16、1080×1920、30fps，约 3 分钟；内容逻辑和重要互动优先于固定时长。当次用户要求覆盖这些默认值。

## 沿用或迭代

- 新片：先看实际素材，按活动主题分组，再沿用本 skill 的视觉资产。默认中文短标题与活动说明。
- 已有片：保留已确认的模板和未涉及的内容，按具体反馈修改。用户认可模板，不代表认可每一处声音或镜头取舍。
- 风格迭代：在现有纸张、墨线、照片卡片和贴纸语言中调整颜色、装饰、节奏或章节。不自动更新全局 skill；用户说“以后统一用这一版”或明确要求更新 skill 时，再保存新基准。

制作前读取 [风格与剪辑准则](references/style-and-editing.md)。视觉资产为 `assets/style-spec.json`、`assets/layout.css` 和 `assets/illustrations/`。放入新工程时运行：

```bash
python3 <此 skill 目录>/scripts/scaffold.py --project <工程目录>
```

脚本只复制风格资产，不生成素材、时间线或成片。按实际素材编排完整工程。默认使用当前环境可用的 HyperFrames：先读取其入口 skill，按路由使用 composition、media 和 audio 能力；用户指定其他工具时，沿用这里的视觉和剪辑准则。

## 长期偏好

- 保留照片和视频的完整构图与原速。横屏按比例嵌入竖屏；装饰放在源画面外。不擅自裁切、拉伸、变速、改人物或套风格滤镜。HDR 到 SDR 的播放兼容转换与创意调色分开处理。
- 用“做什么—怎么做—结果/反应”组织每个主题。主题数量随素材变化，不固定成国庆片的五章。
- 小朋友的祝福、反应和吹蜡烛等重要互动，查看原片前后并保留完整句子与动作。重复成人长合唱可以缩短，让儿童互动承担重点。
- 轻松欢快的器乐配乐，家人说话时降低音乐。默认保留有意义的现场声。
- 消音按当次要求定位；不把这次几句方言和厨房女声的修改泛化成“所有方言或成人声音都删除”。混合人声不能单独去掉一人时，说明影响，优先缩短重复段、保留儿童独立发声片段。
- 字幕是活动说明；核实原声后才能写逐字对白。不要推测姓名、亲属关系、地点或日期。

## 完成交付

交付 MP4、可编辑工程，以及素材主题分类和源片使用范围。保留源文件。先制作可看的具体结果，再根据反馈迭代，不把重复确认作为默认步骤。

导出与更新成片时，读取 [导出与验证](references/delivery.md)。检查实际 MP4 的声音、儿童互动结尾、音画同步和视频轨时长，不能只依据工程预览宣布完成。

# 已确认的家庭手账风格

复用设计资产，不携带上一部影片的照片、声音、姓名或文件路径。

## 视觉语言

奶油色方格纸、海军蓝墨线、彩色胶带、白色照片卡片、手绘活动图案、带边框和错位阴影的贴纸字幕。整体活泼、明亮、有设计感。章节页需要真实素材照片和手绘元素，不能退回大块纯色底加一行文字。

| 用途 | 颜色 |
|---|---|
| 纸张 | #FFFBF0 |
| 墨线 / 文字 | #233B50 |
| 玩耍 / 开场 | #FFD84A |
| 动手 / 厨房 | #82DBBD |
| 田野 / 收获 | #FFB86B |
| 户外 / 探索 | #8CD3ED |
| 团聚 / 生日 | #F6A5BC |

颜色是主题语义建议，不要求每部片包含这些活动。以每场的 `--accent` 选色。清楚、稍圆润的中文无衬线，标题粗体。CSS 支持 `--family-font`，默认系统中文字体；嵌入字体需有许可，并针对当前字幕重新生成子集。

## 已验证的竖屏布局

以下坐标以 1080×1920 为基准，其他尺寸按比例缩放并重新检查。

| 元素 | 区域 |
|---|---|
| 章节顶栏 | 左 80、右 75、上 47，高 90 |
| 日期 / 家庭影片小标记 | 左 99、上 151；使用当次信息 |
| 白色照片框 | 左 92、上 204，896×1568 |
| 完整源画面 | 左 108、上 220，864×1536，object-fit: contain |
| 底部贴纸字幕 | 左右 80、上 1795，高 87 |
| 章节照片卡片 | 左 175、上 340，730×1030 |
| 章节大标题 | 左右 90、上 1450 |

横屏素材完整显示，其上下留白可以放手绘图案和主题标签；先检查该素材实际显示边界，不压到画面。章节照片卡片可轻微旋转，正文真实视频不旋转、不推近。

基本 DOM 类名与 CSS 对应：

```html
<div class="scene-root" style="--accent:#82DBBD">
  <div class="stationery">
    <div class="paper-edge"></div><div class="frame-paper"></div>
    <div class="tape tape-a"></div><div class="tape tape-b"></div>
  </div>
  <div class="topline">
    <div class="chapter-title">一起动手</div>
    <div class="chapter-number">02 / 04</div>
  </div>
  <video class="media" src="当前素材"></video>
  <div class="caption"><span>认真试一试</span></div>
</div>
```

这是视觉示意。用于 HyperFrames 时补上稳定 id、timing、轨道和媒体播放属性，由框架管理媒体。章节页使用 `.card-back`、`.card-polaroid`、`.card-icon`、`.card-sticker`、`.card-sun` 和 `.card .number/.title/.tag`。编号总数随章节调整；CSS 的 `--chapter-count` 可替换默认 `/ 05`。

短章标题、照片卡片和贴纸轻轻弹入，常见 0.25–0.5 秒；原片动作承担主要节奏。采用可确定、可 seek 的动画，不为热闹堆叠转场和音效。配色迭代修改工程自己的资产，保留这个 skill 基准。

## 从素材到故事

查看视频前、中、后和完整照片，记录主题、活动、起止与声音。不能只看首帧或文件名。每章建立动作链，如寻找—发现—制作—品尝，或祝福—唱歌节选—吹蜡烛—反应。团聚可收尾，前提是素材支持。

删重复角度和等待，保留新信息、儿童表情、家人互动及完整结果。照片承担章节包装、活动结果和短暂换气。先照顾动作连续性，再用短说明帮助理解，不补写未发生的情节或虚构对白。

## 声音取舍

配乐优先轻松的尤克里里、木琴或类似器乐，可换曲。使用允许当前用途的音乐并记录署名。轻淡入、自然淡出；原声说话时压低音乐，重要祝福必须听清。

时间点反馈先在当前成片定位，再映射到源片。区分只去声音与删除画面。短句消音采用短淡入淡出避免爆音，不影响相邻儿童发言。重叠人声不能可靠拆开时，不声称单独去掉某个人；说明影响，选取独立发声片段或删去重复合唱。

生日须检查原片末尾：完整保留祝福、准备吹、实际吹灭和紧随其后的反应。成人长合唱可删减，儿童简短祝福和唱歌按用户要求完整保留，不用重复合唱挤掉吹蜡烛。

国庆片的具体消音时间点不是未来影片规则，新素材必须重新定位。

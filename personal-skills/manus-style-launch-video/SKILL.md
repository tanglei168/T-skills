# Manus 风格产品发布视频

独立编写的制作工作流，使用 HyperFrames 作为渲染依赖。视觉参考以用户选定的 Skillry Muse Demo 为主，Skillry Demo 为第二参考：瓷白画布、精简标题、纵向章节词列、真实界面与短暂揭晓留白。音乐默认使用用户提供的原创 122 BPM 提示词方案，以连续主题推进。Mole 英文版是历史制作案例，不等于与 Demo 已匹配。它是用户自己的产品视频，不是 Manus 官方作品或 Skillry 付费包的复刻。

## 先确认正在做什么

- 新产品：从官网、简报和真实素材建立事实与分镜，按品牌调整默认风格。
- 修改现有片：读取已有时间线、交付记录和本轮意见，保留已认可的内容；不要重新做无关段落。
- 只改配乐：完成音轨编辑后使用随附替换脚本复用原视频画面，避免重渲整片。
- 只改语言：同时更新标题、章节、提示、收尾和官方对应语言的界面，重新核对布局与镜头目标。

制作／修改视频时先读取可用的 `/hyperframes` 入口，再按需要加载其核心、动画、媒体、音频及 CLI 模块。此 Skill 提供创意与制作经验，不替代当前引擎契约。

## 已固化的默认方向

默认 16:9、1080p、30fps、约 110 秒、无旁白；语言、片长、比例与叙事服从当前用户要求。这是可调整的基线，不把 Mole 的品牌、五项功能或具体时间点套到其他产品。

- **视觉：** 暖白画布与深色章节交替，一个镜头一个焦点；大字、真实 UI 和少量品牌图形承担画面。优先产品自己的品牌素材，星球、风景和玻璃卡片只在适合该产品时使用。
- **结构：** 品牌／问题 → 核心承诺 → 能力概览 → 章节与界面证据 → 用户价值／控制感 → 留白揭晓 → 压轴证据 → 品牌与网址。能力数量随产品选择；没有真实压轴内容时用价值总结收尾。
- **界面：** 全景建立上下文 → 推近真实功能目标 → 给出价值落点或回到全景。静态截图镜头不伪装成真实点击录屏，官方示例数字明确说明。用户要求模拟点击时，加自然的鼠标接近、短停、按下／释放和克制接触反馈；跟随 UI 镜头坐标，标注模拟，不虚构操作结果。
- **语言：** 英文使用短、自然的产品文案；保持语义和可信主张，不逐字翻译中文。中文按词组做动效。品牌与应用专名可保留原文。
- **音乐：** 新的默认方案是 122 BPM、4/4、约 110 秒的原创电子流行／轻 House 纯音乐，同一个克制旋律主题贯穿六段编曲；读 [原创配乐方案](references/original-122-score.md)。原创新作必须实际生成或作曲，不能以库存曲、改名或短循环铺满代替。用户要求与 Muse 一样时，先取得准确原曲或明确曲目来源；不按 House 标签、BPM 或动态范围选一首替代后宣称一致。Skillry 为完整备选方向，不能默认将两支曲子拼接。使用相同源曲时让镜头服从原曲段落，避免为了既有 120 BPM 网格改变曲速。

## 制作与迭代

1. **建立证据。** 从用户提供的产品资料确认核心卖点、真实界面、品牌与压轴内容，保存来源。缺少核心事实才提问。功能、性能、数量和兼容要求不能凭猜测补充。
2. **落实叙事与主题。** 创建或更新 `brief.md`、`facts.md`、`storyboard.md`，按视觉参考配置令牌。复制风格的组织方法，替换产品事实、文案与品牌资产。
3. **取得音乐并写时间线。** 有已认可音乐时复用；没有时按当前原创／授权选曲需求取得有段落结构的完整配乐。明确要求原创时执行原创流程，不能回退到第三方歌曲并宣称完成。分析当前实际音轨，记录源区间、拍点、增益、交叉淡化与片尾。可先做无声草稿，但不能称其为已卡点成片。
4. **实现确定性场景。** 使用本地字体与素材、一个可寻址根时间线。新产品／新组件先做代表性短段验证；沿用已验证工程的小修改无需重做整个制作闭环。
5. **有针对性地验收。** 先检查改动可能影响的部分，再完成最终交付检查。语言切换核对全部文案与镜头目标；配乐修改核对乐句、揭晓落点、响度和峰值。只修改音轨时证明画面流未改变。
6. **直接完成已授权交付。** 用户要求成片或自行调整时完成本地导出；明确要求先审片时先给预览。外部付费生成、上传或发布只按已有授权与范围执行。

无法听取音频时用来源与解码测量说明依据，不声称已听出乐器或鉴定原曲；让可播放的实际成片承载听感评审。无法观看整片时也不声称看完，报告完成的解码、关键帧与跳转验证。

## 工程与交付

每次修改保留前版，给新版本稳定的目录与文件名。交付事实／素材来源、分镜／时间线、可编辑工程、本地素材、MP4 与简短检查记录。音乐记录包含名称、作者、来源、许可及编辑参数；不把第三方音乐称为原创，不额外打包原曲供独立下载。

动画由时间直接决定；同一时间点从前或从后跳转得到相同画面。字幕、标题和镜头都服从同一时间线。更换语言截图后重新定位按钮，不沿用旧坐标。

## 随附脚本

- `python3 scripts/compose_original_122.py --out <工程>/score`：明确选择本地合成方案时，制作完整 110 秒原创五分轨配乐；需要 NumPy、SciPy，输出未母带化 WAV 与事件账本。不是在线音乐模型，适用范围见原创配乐参考。
- `python3 scripts/validate_timeline.py <工程>/timeline.json`：检查帧区间、素材及事实引用。
- `python3 scripts/render_local.py <工程> --cli <路径> --quality delivery`：本地渲染已通过检查的工程，可指定 Chrome、FFmpeg、FFprobe 和输出路径。
- `python3 scripts/replace_soundtrack.py <原片.mp4> <完成的配乐.m4a> <新版.mp4> --ffmpeg <路径> --ffprobe <路径>`：替换音轨，保留原画面压缩流，核对时长与画面哈希、完整解码并输出检查记录。

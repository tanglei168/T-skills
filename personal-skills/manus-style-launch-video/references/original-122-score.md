# 原创 122 BPM 产品发布配乐

用户于 2026-10-08 给出的新方向：原创纯音乐、122 BPM、4/4、约 110 秒，电子流行加轻 House，明亮、温暖、自信、有一点俏皮，但克制。当前需求覆盖过去的目录选曲。不要把“更高级”解释为更响、更重低频或更多转场音效。

## 提示词与音乐契约

使用 [原文提示词](../assets/original-launch-score-prompt.txt)，保持同一个简单旋律主题贯穿全片，通过配器、音区、和声和层数发展；速度始终不变。鼓干净紧致，kick 柔和圆润，clap 克制，hi-hat 细致，贝斯温暖有脉冲，拨弦合成器带铃音，和弦空气感充分。不要人声、说话、vocal chop、失真主音、攻击性低频、音乐节 drop、夸张管弦乐或长 riser。

| 时间 | 编曲 | 声画关系 |
|---|---|---|
| 0–8s | 稀疏主题、轻脉冲 | 品牌／短引子，不用满编曲抢画面 |
| 8–54s | 稳定律动，逐渐加入贝斯和打击乐；每 8 小节短暂减层 | 功能章节、真实 UI；用拍点定位文字和重要镜头 |
| 54–80s | 更明亮和弦、少量附加打击乐、略宽合成器 | 更温暖的价值和产品证据，不能加速 |
| 80–87s | 鼓／贝斯收回，主题柔和地保留 | 揭晓前留白，保持乐句连续 |
| 87–104s | 同一主题最完整的版本 | 压轴功能／最终揭晓在回归拍进入 |
| 104–110s | 减层、解决和弦、短自然混响尾 | 品牌与网址稳定可读，音乐有明确句点 |

这是当前方案，不是所有产品的固定时长。用户改变片长时重新写乐句和结尾；不能简单裁尾、变速，或把 28 秒生成片交叉淡化循环成 110 秒。

## 实际制作路径

先检查当前可用音乐工具和已有凭据，再选择原创新作方法。在线音乐生成时提交完整提示词并取得实际音频，核对时长、主题连续性、六段编曲和尾音；模型接受文字提示不等于成品真的遵守 BPM。记录服务、模型、生成参数与素材来源，不虚构服务或曲目身份。费用与账户动作服从用户授权。

没有对应服务时保持原创要求；可以在任务已授权的范围内采用完整本地作曲与合成，并明确它不是在线生成模型。随附 `scripts/compose_original_122.py` 是此种方法的可编辑基线：Python 3.12+，NumPy、SciPy；48 kHz、110 秒、D 大调、两小节旋律动机、近距离 add9／maj7 和声、五个分轨、两次八小节减层、无鼓贝斯的揭晓留白、A→D 解决和弦和短尾音。每个音符／鼓击都写入事件账本，音频直接合成，不拼库存歌曲或重复整段短音频。

```sh
python3 -m venv .audio-runtime
.audio-runtime/bin/python -m pip install numpy scipy
.audio-runtime/bin/python scripts/compose_original_122.py --out /path/to/project/score
```

输出 `premaster.wav`、`motif.wav`、`chords.wav`、`bass.wav`、`drums.wav`、`percussion.wav` 与 `composition.json`。脚本默认拒绝覆盖已有生成文件，需要重做时选择新目录或明确传入 `--overwrite`。这些是未母带化素材；重新生成后测响度和真峰值再设固定增益，不能把某一次的 6.25 dB 当通用值。根据真实反馈修改动机、和弦、音色或编曲；“原创”不自动证明听感达到用户要求。

本地音色适用克制的合成器电子乐；需要真实演奏、其他编曲或特定音乐模型时换对应制作路径，不假称此脚本已经覆盖。

## 声画对齐与验收

122 BPM 每拍约 0.491803s，每小节约 1.967213s。生成模型应分析实际拍点，本地事件作曲可直接读取账本。视频边界对齐 30fps，允许与音频拍点相差半帧；不要为了凑 110 秒把 122 改成 120。将点击安排在镜头稳定的拍点，保持鼠标到达、短停、按下／释放和退场。当前样例的揭晓落在第 177 拍（87.049s），解决和弦落在第 212 拍（104.262s）。

核对实际音频：完整 110 秒、无未授权曲目、主题持续、八小节减层、80–87 秒主题保留而鼓贝斯收回、结尾解决并平稳到零。对最终 AAC／MP4 再测响度与峰值，保留空间和段落差异；通常从 −17 至 −16 LUFS、至少 1.5 dB 真峰值余量开始。测量不能代替主观音乐评价。不能听取时，不宣称已完成试听或“已达到高级感”。

视频片长和镜头位置也改变时重新渲染全片，检查最终编码的按钮、底边、揭晓与收尾。交付实际视频、独立音轨、可编辑工程、作曲源文件和分轨；只保存提示词不算完成音乐修改。

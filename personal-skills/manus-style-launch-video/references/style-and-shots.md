# 视觉、镜头与语言的默认风格

先读 [muse-skillry-target.md](muse-skillry-target.md) 的当前参考方向。下面的字号与动画秒数是历史 Mole 工程的可调整起点，不是 Demo 原始 CSS 或已验证的逐帧复刻参数。具体令牌在 assets/style-preset.json；产品品牌或用户要求优先。

## 构图与层级

在 1920×1080 设计坐标下：Muse 中性瓷白约 #f6f6f6（Skillry 第二配置约 #f6f3ec）、深底 #0c1119、深色正文 #1c2024，强调色取产品。Mole 范例用 #456f97。正文、标题和安全区保持清晰层级，画布等比缩放。

- 关键节点的大字可从约 108–150px 开始试排；主体价值句按构图使用较小字号，不把全片都做成大字；英文长句缩短内容或降低字号，不用压扁字体解决。
- UI 场景头部约 40–48px，短提示约 28–34px，示例数据说明约 20–24px。
- 英文可用本地 DM Sans 400／700；中文可用 Noto Sans SC。优先已有品牌字体，保存来源与许可。
- 文字一般落在宽度约 6%、高度约 5% 的安全区内。入口、字幕与 UI 信息之间留出空间。

一个镜头只保留一个主焦点。主品牌形状使用官网资产；星球是 Mole 的品牌视觉，不是此风格对所有产品的要求。风景、玻璃和装饰图只在有明确叙事价值时使用，不为填满画布添加。

## 镜头语言

| 类型 | 功能 | 时长起点 | 动作 |
|---|---|---:|---|
| brand／opening | 建立品牌或问题 | 小 Logo 约 2–3 秒后进入短句 | 以 Muse 黑底小 Logo 为当前参考，不长时间铺巨型品牌图形 |
| kinetic-title | 提炼价值 | 4–6 秒 | 语义词组错峰上移，落定后留阅读时间 |
| orbit／能力概览 | 建立产品能力地图 | 3–5 秒 | 仅产品已有图形轻微错峰，随后概览句 |
| chapter | 声明下一项能力 | 1.5–2.5 秒 | 深底、稳定前缀、三行裁切窗口；中行突出 |
| ui-demo | 用真实界面给证据 | 7–11 秒 | 全景 → 功能目标 → 结果／全景，通常 2–3 次聚焦 |
| value-card | 表达控制感或产品价值 | 5–7 秒 | 一个总标题，少量短卡片，不堆功能 |
| reveal | 给压轴内容建立期待 | 约 2–4 秒候选，服从实际音乐 | 短标题分组进入，音乐收弱，紧接真实证据 |
| end-card | 品牌与行动引导 | 5–7 秒 | 品牌、短收尾句、一个网址；停留足够读完 |

能力少时减少章节，不硬填满 90 秒。压轴没有事实时不暗示不存在的新功能。

## UI 聚焦

先显示可辨认的全景，再推近能证明本段主张的区域。可从 1.35–1.75 倍开始调；必要时更近，但必须维持截图清晰度、产品上下文与镜头边界。聚焦动作通常 0.55–0.75 秒，落点保持约 1–2 秒后再移动。

每个目标记录图片路径、裁切矩形、归一化坐标、镜头倍率和进入时间。夹取镜头偏移，防止图片边缘之外露出空白。短提示不能盖住需要展示的按钮或数据。

截图只做镜头移动时使用“Official interface · Sample data”等可读说明；不要画虚构点击、进度或清理完成结果。真正的录屏可按实际操作使用光标与点击提示。

## 英文内容切换

同时替换品牌句、主题句、章节、UI 标题、短提示、卡片、揭晓、CTA 与兼容说明。优先官网英文界面；应用专名与文件路径可以保留原文。

英文文案写短的自然产品句，保留事实语义与重点。Mole 范例包括 “Make room for what matters.”、“Five tools. One app.”、“Every step. Your call.”；其他产品应重新写，不沿用 Mole 的承诺。

逐一检查：长单词是否被章节窗口截断、卡片正文是否超过高度、标题与右侧说明是否相撞、不同 span 之间的空格是否折叠。英文和中文截图的按钮可能不在同一位置，重新定位后再渲染。

## 克制的运动

常规入场约 0.35–0.65 秒，标题／界面采用清晰的减速与加减速曲线。章节换词可轻微回弹，但避免持续抖动、旋转或每个元素都弹跳。主要切场与音乐强拍对应，内部动作可以隔两拍／四拍发生。

大字按词组拆分，介词或单个汉字不机械占一拍。完成入场后保持稳定阅读，不为了通过检查加无意义漂移。所有动作都必须可确定地跳转。

验收看各场中点、聚焦落点、转场前后和最终小尺寸播放。调整文字时检查字体与词间距；调整截图时检查焦点与边界；不只依赖自动检查通过。

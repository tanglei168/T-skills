# 已验证范围

核对日期：2026-10-01。真实产品是 Mole；已完成中文与英文 90 秒片，16:9、1920×1080、30fps。第二个产品的组件迁移仍未实测。

## 实际跑通的路径

- 官网真实界面、标志与星球素材落成本地文件，并保留事实与素材来源。
- 本地 GSAP 的暂停根时间线驱动标题、深色章节、界面推近、价值卡片和揭晓；八个前后跳转检查得到一致画面。
- 中文版使用 Noto Sans SC，英文版使用 DM Sans；官方英文 UI 替换后重新检查排版与按钮位置。
- HyperFrames 0.8.96 完成原制作与浏览器检查；配乐优化工程从 0.8.96 升至 0.8.99 后兼容检查通过。
- 英文完整片为 2700 帧，H.264、AAC 立体声，完整解码无错误。CLI 渲染遇过浏览器／编码超时，使用已检查的单根时间线逐帧缓存与独立编码完成；该备用方法只验证于本案，不视为任意含视频或嵌套场景工程的通用渲染器。
- 最终配乐由自制循环／Your Breath 迭代为有许可的 Deep Urban。最新混音保留连续乐句和安静／完整编曲段落，最终只用固定增益。
- 音轨修改采用成片重封装，视频流保持原样；前后压缩流 SHA-256 相同。完整成片解码与音轨测量通过。

## 固化后的证据边界

该工作流验证了本地素材、官方静态 UI 的镜头动画、英文切换、配乐选择／编辑与成片音轨替换。没有执行产品清理，没有把静态截图包装成真实点击操作，没有验证全部新产品，也没有识别三个 Skillry 样例的原曲名。

最新版示例的详细节奏与实际音频结果见 mole-english-case.md。音乐文件属于具体项目与对应许可，Skill 包内不捆绑第三方原曲。随附脚本应在新环境明确指定依赖，并对真实交付验证。

2026-10-08：已完整测量三个公开 Demo 并修正目标为 Muse／Skillry，详见 muse-skillry-target.md。技术通过与更大的动态不等于参考风格一致；原曲未确认，尚未制作相同原曲的新片。

## 2026-10-08：原创 122 BPM 与 110 秒同步版本

Mole 英文版以用户原文提示词重做配乐：本地完整作曲／合成，不使用在线模型、库存原曲或短音频重复拼接。110 秒、122 BPM、4/4、48 kHz 立体声；五个分轨与音符／鼓击账本可编辑。实际分轨检查确认 80.15–86.9 秒鼓贝斯低于 −100 dBFS、旋律主题保留；最后 100 个采样低于 −80 dBFS。独立 AAC 为 −16.61 LUFS、−2.90 dBTP；MP4 为 −16.64 LUFS、−3.15 dBTP、6.0 LU 响度范围。数值是本案结果，不能替代主观听感认可。

23 个场景重排到 3300 帧，One More Thing 在 80–87 秒依次进入，AI 揭晓接第 177 拍，片尾接第 212 拍。三处模拟点击保留：Review results、Remove 3、Optimize；同 UI camera 坐标，样例和模拟标注，没有执行产品操作或虚构结果。

HyperFrames 0.8.140 配合 CLI 管理的 chrome-headless-shell 完成 1920×1080、30fps、110 秒本地导出。严格浏览器检查 12 个采样点零错误／警告；最终 MP4 完整解码通过，检查了 13 个编码关键帧及三处 UI 底边。此前桌面 Chrome 的底部裁切问题未出现在该输出。此处不声称听完并认可音乐，或已验证其他产品。

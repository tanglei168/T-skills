# 已验证范围

核对日期：2026-10-01。真实产品是 Mole；已完成中文与英文 90 秒片，16:9、1920×1080、30fps。第二个产品的组件迁移仍未实测。

## 实际跑通的路径

- 官网真实界面、标志与星球素材落成本地文件，并保留事实与素材来源。
- 本地 GSAP 的暂停根时间线驱动标题、深色章节、界面推近、价值卡片和揭晓；八个前后跳转检查得到一致画面。
- 中文版使用 Noto Sans SC，英文版使用 DM Sans；官方英文 UI 替换后重新检查排版与按钮位置。
- HyperFrames 0.8.96 完成原制作与浏览器检查；配乐优化工程从 0.8.96 升至 0.8.99 后兼容检查通过。
- 英文完整片为 2700 帧，H.264、AAC 立体声，完整解码无错误。CLI 渲染遇过浏览器／编码超时，使用已检查的单根时间线逐帧缓存与独立编码完成；该备用方法只验证于本案，不视为任意含视频或嵌套场景工程的通用渲染器。
- 最终配乐由自制循环／Your Breath 迭代为有许可的 Deep Urban。最新混音保留连续乐句和安静／完整编曲段落，最终只用固定增益。
- 音轨修改采用成片重封装，视频流保持原样；前后压缩流 SHA-256 相同。完整成片解码与音轨测量通过。

## 固化后的证据边界

该工作流验证了本地素材、官方静态 UI 的镜头动画、英文切换、配乐选择／编辑与成片音轨替换。没有执行产品清理，没有把静态截图包装成真实点击操作，没有验证全部新产品，也没有识别三个 Skillry 样例的原曲名。

最新版示例的详细节奏与实际音频结果见 mole-english-case.md。音乐文件属于具体项目与对应许可，Skill 包内不捆绑第三方原曲。随附脚本应在新环境明确指定依赖，并对真实交付验证。
